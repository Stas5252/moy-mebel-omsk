# Границы, решённые в спецификации

## Правила проекта

- Статический сайт без package manager и тест-раннера.
- Локальная проверка: `python -m http.server <порт> --bind 127.0.0.1 --directory .`.
- Не устанавливать зависимости и не изменять минифицированные Tilda-файлы без подтверждённой необходимости.
- При недостающем инструменте вернуть `BLOCKED`, не устанавливать его.

## Модули и швы

| Модуль | Владеет | Выставляет | Прячет |
|---|---|---|---|
| `css/unified-design-system.css` | Общие шапка, подвал и breakpoints | Классы `.site-header*`, `.site-footer*` | Декоративные детали страниц |
| `index.html`, `mebel.html`, `raspil.html` | Контент и локальные блоки | Семантические ссылки, изображения, формы | Встроенные стили и Tilda-разметку |

Шов для проверки: страницы загружаются локально по HTTP; браузер измеряет переполнение, загрузку ресурсов и ошибки консоли.
